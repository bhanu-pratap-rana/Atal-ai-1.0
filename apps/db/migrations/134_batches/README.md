## Quick Start (Recommended)

### Option A: Run Batch Script (Fastest)

1. Get your DATABASE_URL from Supabase Dashboard:
   - Go to https://supabase.com/dashboard/project/hnlsqznoviwnyrkskfay/settings/database
   - Copy the "Connection string" (URI format)
   - It looks like: `postgresql://postgres:[PASSWORD]@db.hnlsqznoviwnyrkskfay.supabase.co:5432/postgres`

2. Run the script:
   ```bash
   cd apps/db
   DATABASE_URL="postgresql://postgres:[YOUR-PASSWORD]@db.hnlsqznoviwnyrkskfay.supabase.co:5432/postgres" node scripts/run-134-batches.cjs
   ```

   Or set it permanently in `apps/web/.env.local`:
   ```
   DATABASE_URL=postgresql://postgres:[YOUR-PASSWORD]@db.hnlsqznoviwnyrkskfay.supabase.co:5432/postgres
   ```
