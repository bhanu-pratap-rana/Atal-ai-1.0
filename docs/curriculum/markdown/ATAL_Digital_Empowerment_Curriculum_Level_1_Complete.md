**Unit 1: What is a computer?**

**Topic 1.1: The Four Jobs of a Computer (I → P → O → S)**

**Learning Outcome:** Explain the four basic jobs of all computers.

**Simple Explanation**\
Every computer does 4 things: **Input → Processing → Output → Storage**.

-   **Input**: You give information (keyboard/mouse/touch).

-   **Processing**: Computer brain (CPU) works on it.

-   **Output**: You see results on screen/speakers/print.

-   **Storage**: Files saved for later (safe even when power is off).

**Visual Guide (printable)**

INPUT → PROCESSING → OUTPUT → STORAGE

keys/touch CPU \"thinks\" screen/sound hard drive/SSD/USB

**Cultural Analogy --- Village Community Hall**

-   **Input** = people submit requests at the desk

-   **Processing** = hall manager plans and assigns work

-   **Output** = announcements/results shown on the board

-   **Storage** = records kept safely in the office cupboard *(bhandar /
    ভাণ্ডাৰ)*

**Step-by-Step Example**

1.  Type a line in a note app → **Input**

2.  CPU arranges letters → **Processing**

3.  Text appears → **Output**

4.  Press **Ctrl + S** to save → **Storage**

**Common Mistakes & Tips**

-   ❌ Thinking "processing" is only for maths → ✅ It includes *any*
    computer work (typing, photos, forms).

-   ❌ Forgetting to save → ✅ Press **Ctrl + S** every 10 minutes.

**Quick Practice (device)**\
Open a note app, type your name, read it on screen, then save as
My_Name.txt.\
**Low-Tech Option**: Draw the 4-arrow diagram and label with local
examples.

**Privacy & Safety Context**\
On shared computers, save only inside **your named folder** or your own
USB. Don't leave files on Desktop/Downloads.

**Assessment (MCQ)**

1.  **Easy**: Which is the correct order?\
    a) Processing → Output → Input → Storage\
    b) **Input → Processing → Output → Storage** ✓\
    c) Output → Input → Storage → Processing\
    d) Storage → Output → Input → Processing\
    **Why?** All computers follow this flow for any task.

2.  **Medium**: When you press **Ctrl + S**, which job is that?\
    a) Input\
    b) Processing\
    c) **Storage** ✓\
    d) Output\
    **Why?** Saving keeps your work for later.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓, 2-c ✓\
**🏅 Badge Progress:** **1/10** Computer Basics Badge

**Topic 1.2: Main Parts You See and Use**

**Learning Outcome:** Identify the common parts and what they do.

**Simple Explanation**

-   **Monitor (screen)**: shows text & pictures *(output)*

-   **Keyboard/Mouse/Touch**: you give commands *(input)*

-   **CPU/System Unit**: computer brain *(processing)*

-   **Storage (HDD/SSD/USB)**: keeps files safe *(storage)*

**Visual Guide (printable)**

\[ Monitor \] ← output

\[ Keyboard \] \[ Mouse/Touch \] ← input

\[ System Unit / CPU \] ← processing

\[ HDD/SSD/USB \] ← storage

**Cultural Analogy --- Weekly Haat (Market)**

-   **Stalls** = monitor displays items

-   **Customers giving orders** = input

-   **Market manager** = CPU organizes work

-   **Store rooms** = storage for goods

**Step-by-Step Example**\
Point to each part and state its job in your own words.

**Common Mistakes & Tips**

-   ❌ Calling the monitor "CPU" → ✅ CPU is inside the system
    unit/laptop/phone.

-   ❌ Thinking USB is the same as RAM → ✅ USB is storage (permanent),
    RAM is temporary.

**Quick Practice (device)**\
Find each part on your device (or phone equivalents).\
**Low-Tech Option**: Draw and label a simple computer.

**Privacy & Safety Context**\
Ask before using others' devices; don't change settings. Wipe
screen/keyboard with a dry cloth only.

**Assessment (MCQ)**

1.  **Easy**: Which part is *output*?\
    a) Keyboard\
    b) **Monitor** ✓\
    c) Mouse\
    d) USB\
    **Why?** Output shows results.

2.  **Medium**: Which is the "brain"?\
    a) **CPU/System Unit** ✓\
    b) Monitor\
    c) Keyboard\
    d) USB\
    **Why?** CPU controls all work.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓, 2-a ✓\
**🏅 Badge Progress:** **2/10** Computer Basics Badge

**Unit 2: Memory and Storage**

**Topic 2.1: RAM vs Storage --- Work Table vs Cupboard**

**Learning Outcome:** Tell the difference between temporary RAM and
permanent storage.

**Simple Explanation**

-   **RAM (work table)**: holds what you're using *right now*; clears
    when power is off.

-   **Storage (cupboard)**: holds files for months/years; safe after
    power off.

**Visual Guide**

RAM (Work Table) STORAGE (Cupboard)

• Temporary (clears) • Permanent (stays)

• Very fast • Larger capacity

• For open apps now • For saved files

**Cultural Analogy --- Rice Threshing vs Granary**

-   **RAM = Daily threshing area** (quick, cleared often)

-   **Storage = Community granary** (organized, long-term safe)

**Step-by-Step Example**\
Type text → in RAM. Save → goes to storage. Turn off → RAM clears;
storage keeps file.

**Common Mistakes & Tips**

-   ❌ "RAM and storage are same" → ✅ RAM is *temporary*, storage is
    *permanent*.

-   ❌ Not saving regularly → ✅ Press **Ctrl + S** every 10 minutes.

**Quick Practice (device)**\
Type a line; close app without saving; reopen---text is gone (RAM
cleared).\
**Low-Tech Option**: Two labeled boxes (RAM/Storage) and paper "files"
to move.

**Privacy & Safety Context**\
Power cuts? Save often and keep a backup on USB *(nokol rakhibo / নকল
ৰাখিব)*.

**Assessment (MCQ)**

1.  **Easy**: What happens to RAM when power is off?\
    a) Stays\
    b) **Gets cleared** ✓\
    c) Moves to USB\
    d) Doubles\
    **Why?** RAM is temporary.

2.  **Medium**: Why more RAM helps?\
    a) More photos saved\
    b) **More apps open smoothly** ✓\
    c) Faster internet\
    d) Brighter screen\
    **Why?** RAM supports multitasking.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓, 2-b ✓\
**🏅 Badge Progress:** **3/10** Computer Basics Badge

**Topic 2.2: Save Habits that Survive Power Cuts**

**Learning Outcome:** Use simple habits so work is not lost.

**Simple Explanation**

-   Save early and often (**Ctrl + S**).

-   Use **Save As** with clear names and correct folders.

-   Turn on *AutoSave/Auto-Recover* where available.

**Visual Guide**

EVERY 10 MINUTES: Ctrl + S

END OF DAY: Save As → Backup_YYYY_MM on USB/phone

WEEKLY: Test-open your backup files

**Cultural Analogy --- Evening Shop Closure**\
Before closing, shopkeepers count cash, lock cupboards, and keep a copy
of records---same with files.

**Step-by-Step Example**

1.  Save with a good name; 2) End of day, copy to USB; 3) Open the copy
    to confirm.

**Common Mistakes & Tips**

-   ❌ Only one copy on desktop → ✅ Keep a second copy on USB/phone.

-   ❌ "I will save later" → ✅ Save as you go.

**Quick Practice (device)**\
Make a short note, save, then make a **USB copy**. Open the copy to
test.\
**Low-Tech Option**: On paper, plan a daily "save & backup" checklist.

**Privacy & Safety Context**\
On shared PCs, never leave work in Downloads/Desktop. Use **YourName**
folder or your USB.

**Assessment (MCQ)**

1.  **Medium**: Best habit to survive power cuts?\
    a) Save once at the end\
    b) **Save every 10 minutes and keep a backup** ✓\
    c) Use only RAM\
    d) Keep app open\
    **Why?** Frequent saves + backup protect your work.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓\
**🏅 Badge Progress:** **4/10** Computer Basics Badge

**Topic 2.3: Backup Basics --- The Simple 3-2-1 Rule**

**Learning Outcome:** Keep important files safe using a basic backup
plan.

**Simple Explanation**\
**3-2-1 Rule:** 3 copies total, 2 different places (e.g., device + USB),
1 offsite (e.g., a second USB at home/school).

**Visual Guide**

3 copies = Original + USB + (Second USB / Cloud if available)

2 media = Device + USB

1 offsite = Keep one copy at another safe place

**Cultural Analogy --- Seed Preservation**\
Farmers keep seeds in multiple containers and locations to avoid total
loss.

**Step-by-Step Example**\
Make a **Backups/YYYY_MM** folder → copy key files weekly → test open.

**Common Mistakes & Tips**

-   ❌ Only one copy → ✅ Always maintain at least two.

-   ❌ Never test backups → ✅ Open backups monthly to confirm.

**Quick Practice (device)**\
Pick 3 important files → copy into a dated "Backups" folder → test
open.\
**Low-Tech Option**: Draw a simple backup map (where, how often, who
checks).

**Privacy & Safety Context**\
For personal documents (ID, bank), name them neutrally (e.g.,
ID_Doc_2025.pdf), and store in a private folder/USB.

**Assessment (MCQ)**

1.  **Hard**: Which shows the 3-2-1 idea?\
    a) One copy on Desktop\
    b) **Original + USB + second USB at home** ✓\
    c) Same file in two folders on same PC\
    d) Only email it to yourself\
    **Why?** Multiple places + one offsite.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓\
**🏅 Badge Progress:** **5/10** Computer Basics Badge

**Unit 3: Files and Folders**

**Topic 3.1: What is a File? (Types & Extensions)**

**Learning Outcome:** Identify common file types and what extensions
mean.

**Simple Explanation**\
A **file** holds your information and has a **name** + **extension**:\
.docx (Word), .pdf (fixed doc), .jpg/.png (photos), .mp3 (music), .mp4
(video), .txt (plain text).

**Visual Guide**

Name + Extension = File

School_Essay_Jan2025 .docx

Family_Photo_Bihu2025 .jpg

**Cultural Analogy --- Village Record Books**\
Different books for birth, land, tax: different file types for tasks.

**Step-by-Step Example**\
Create a note → Save As → choose file type → check extension.

**Common Mistakes & Tips**

-   ❌ ".pdf can be edited easily" → ✅ Usually read-only; edit the
    original .docx.

-   ❌ Random names → ✅ Use clear names with purpose + date.

**Quick Practice (device)**\
Create one file of each common type; list where each is used.\
**Low-Tech Option**: Match file types to real-life items on a worksheet.

**Privacy & Safety Context**\
Avoid personal IDs in file names (no Aadhaar numbers). Use neutral
names.

**Assessment (MCQ)**

1.  **Easy**: Which is a photo?\
    a) .mp3\
    b) .pdf\
    c) **.jpg** ✓\
    d) .docx\
    **Why?** .jpg is an image type.

2.  **Medium**: A file that's hard to change is usually...\
    a) .docx\
    b) **.pdf** ✓\
    c) .jpg\
    d) .mp3\
    **Why?** PDFs are commonly shared as final copies.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-c ✓, 2-b ✓\
**🏅 Badge Progress:** **6/10** Computer Basics Badge

**Topic 3.2: Good File Names People Understand**

**Learning Outcome:** Create clear, useful names.

**Simple Explanation**\
Use: **Who/What + Purpose + Date** and \_ or - (no spaces/symbols).\
Example: Ritu_College_Application_2025.pdf

**Visual Guide**

Good: Sharma_Wedding_Jan2025_Ceremony_001.jpg

Bad: IMG_4321.jpg or Doc1.docx

**Cultural Analogy --- Labelled Grain Sacks**\
Write the crop + season + year so anyone can find it fast.

**Step-by-Step Example**\
Rename 5 files with clear names that include purpose and date.

**Common Mistakes & Tips**

-   ❌ Only numbers → ✅ Add words and dates.

-   ❌ Spaces or special symbols → ✅ Use \_ or -.

**Quick Practice (device)**\
Rename 5 messy files into clear names.\
**Low-Tech Option**: On paper, rewrite 6 bad names into good ones.

**Privacy & Safety Context**\
Don't include phone/address/ID in names. Use general titles for
sensitive items.

**Assessment (MCQ)**

1.  **Medium**: Best name for a scholarship form in 2025?\
    a) Form1.pdf\
    b) **Scholarship_Form_2025.pdf** ✓\
    c) MyFile.pdf\
    d) Photo.jpg\
    **Why?** Clear content + year.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓\
**🏅 Badge Progress:** **7/10** Computer Basics Badge

**Topic 3.3: Folders that Make Sense**

**Learning Outcome:** Build a simple, logical folder structure.

**Simple Explanation**\
Folders group related files. Keep depth to 3--4 levels. Example:

**Visual Guide**

📁 My_Documents

📁 School

📁 English

📁 Math

📁 Family

📁 Photos

📁 Papers

📁 Village_Work

📁 Meeting_Notes

📁 Events

**Cultural Analogy --- Organized Kitchen Shelves**\
Main shelves (rice/spices), smaller boxes (varieties), labels (folder
names).

**Step-by-Step Example**\
Create My_Documents → subfolders for School/Family/Village_Work → move
files into correct places.

**Common Mistakes & Tips**

-   ❌ Everything on Desktop → ✅ Keep Desktop clean; store inside
    folders.

-   ❌ Too many levels → ✅ Max 3--4 levels.

**Quick Practice (device)**\
Create the folder tree and move 6 files to correct spots.\
**Low-Tech Option**: Draw your folder tree; file "cards" into it.

**Privacy & Safety Context**\
Set "My_Documents\\YourName" as your home on shared PCs. Clear Downloads
at day's end.

**Assessment (MCQ)**

1.  **Easy**: A subfolder is...\
    a) Broken folder\

    c) Secret folder\
    d) Temporary folder\
    **Why?** "Sub" means inside.

2.  **Hard**: Health worker with 200 patient PDFs---best plan?\
    a) All in one folder\
    b) **Year/Month folders + clear names** ✓\
    c) Only numbers\
    d) Desktop only\
    **Why?** Structure + clear names = quick search.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓, 2-b ✓\

**Topic 3.4: Safe Saving & Simple Backup**

**Learning Outcome:** Save correctly and keep a second copy.

**Simple Explanation**\
Save files in the *right* folder. Keep a second copy in
**Backups/YYYY_MM** on USB/phone.

**Visual Guide**

RIGHT PLACE → Documents\\School\\English

SECOND COPY → USB\\Backups\\2025_09

**Cultural Analogy --- Duplicate Keys**\
Keep a spare key in a safe place, just in case.

**Step-by-Step Example**

1.  Save to correct folder; 2) Copy to USB; 3) Test open.

**Common Mistakes & Tips**

-   ❌ Only desktop copy → ✅ Make a second copy.

-   ❌ Never testing → ✅ Open backup to check.

**Quick Practice (device)**\
Choose 3 important files and back them up to USB.\
**Low-Tech Option**: Draw a two-location backup plan.

**Privacy & Safety Context**\
For shared devices, remove personal files before logging out. Empty
Recycle Bin *after* checking.

**Assessment (MCQ)**

1.  **Medium**: Best second copy location?\
    a) Same folder\
    b) **USB Backups\\YYYY_MM** ✓\
    c) Desktop\
    d) Temp folder\
    **Why?** Second device/place is safer.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓\

**Topic 3.5: Private Info & Safe Sharing**

**Learning Outcome:** Keep personal data protected when naming, saving,
and sharing files.

**Simple Explanation**

-   Use neutral file names (ID_Doc_2025.pdf).

-   Before sharing, remove personal details from the file
    (address/phone/ID), or set *View only* if available.

-   On shared PCs, keep sensitive files only in your folder/USB.

**Visual Guide**

SAFE NAME: ID_Doc_2025.pdf

SHARE: View only (if available)

**Cultural Analogy --- Locked Trunk**\
Important papers are locked and shown only when needed---same idea with
digital files.

**Step-by-Step Example**\
Open file → check for personal details → save a "share copy" without
private info → share that copy.

**Common Mistakes & Tips**

-   ❌ Personal IDs in file names → ✅ Neutral names.

-   ❌ "Anyone can edit" links → ✅ Use "View only."

**Quick Practice (device)**\
Pick one file → make a share-safe copy with neutral name.\
**Low-Tech Option**: On paper, mark which details to remove before
sharing.

**Privacy & Safety Context**\
Never store ID scans on public desktops. Keep them on your USB/private
folder with a strong password *(gupt kodo / গুপ্ত কোড)* for the account.

**Assessment (MCQ)**

1.  **Easy**: Which is safest to share?\
    a) Aadhaar_1234_Rita.pdf\
    b) **ID_Doc_2025.pdf** ✓\
    c) Rita_Address_Phone.pdf\
    d) All_Documents.zip\
    **Why?** Neutral name hides sensitive info.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓\

**Unit 9: Internet Concepts**

**Topic 9.1: What is the Internet? (Networks & Packets)**

**Learning Outcome:** Explain the internet as connected networks
carrying small "packets" of data.

**Simple Explanation**\
The **internet** is a giant network of connected smaller networks. When
you send a message or open a page, information travels in tiny
**packets** through many routes and then re-joins at the destination.

**Visual Guide (printable)**

Your Phone/PC → Local Network (Wi-Fi/4G) → ISP → Internet → Website
Server

(sends small packets in different paths, then re-joins)

**Cultural Analogy --- Assam Trade Routes**\
Like tea moving from garden to town by road, ferry, and rail. Parcels
(packets) may take different paths but reach the same shop (website).

**Step-by-Step Example**

1.  You type a web address.

2.  Your device asks your ISP to find the server.

3.  Data travels as packets across many networks.

4.  The server replies with packets that build your page.

**Common Mistakes & Tips**

-   ❌ "Internet = only Google" → ✅ Internet is many services (web,
    email, chat, maps...).

-   ❌ "One path only" → ✅ Packets can take **multiple routes**.

**Quick Practice (device)**\
Open a website; reload it. Notice how some parts (text) appear before
others (images)---packets arriving.\
**Low-Tech Option:** Draw tea parcels moving along different
roads/ferries to the same market.

**Privacy & Safety Context**\
Anything you send can pass through many networks---use **secure websites
(HTTPS)** and avoid sharing private data on unknown sites.

**Assessment (MCQ)**

    a) One single big computer\
    b) **Many connected networks** ✓\
    c) Only social media\
    d) Only Google\
    **Why?** It's a network of networks.

2.  **Medium:** Your message travels as...\
    a) One large block\
    b) **Small packets** ✓\
    c) SMS only\
    d) Only images\
    **Why?** Data is split into packets.

**Formative check:** ungraded practice only.\
**Answer Key:** 1-b ✓, 2-b ✓\

**Topic 9.2: Ways to Connect (Wi-Fi, Mobile Data, Hotspot)**

**Learning Outcome:** Choose the right connection and manage data costs.

**Simple Explanation**

-   **Wi-Fi:** uses a router; often cheaper for large downloads.

-   **Mobile Data (4G/5G):** uses SIM; portable but data is
    limited/paid.

-   **Hotspot:** one phone shares its data with others.

**Visual Guide**

Wi-Fi (router) ←→ Phone/PC

Mobile Data (SIM) ←→ Phone

Hotspot: Phone A shares data → Phone/PC B

**Cultural Analogy --- Village Water Options**\

(hotspot). Each has cost and limits.

**Step-by-Step Example**

**Common Mistakes & Tips**

    Wi-Fi".

    browser/apps.

**Quick Practice (device)**\

**Unit 10: Safe Browsing**

**Topic 10.1: HTTPS & the Padlock (What it Means, What it Doesn't)**

**Learning Outcome:** Identify encrypted connections and their limits.

**Simple Explanation**

-   **HTTPS + 🔒 padlock** = the connection between you and the site is
    **encrypted** (others can't easily read it).

-   But **padlock ≠ trustworthy content**. A fake site can still use
    HTTPS.

**Visual Guide**

HTTP = not encrypted

HTTPS = encrypted (padlock)

Padlock protects the connection, not the truth of the page

**Cultural Analogy --- Covered Mail Bag**\
A sealed bag hides letters on the way (encryption), but the **letter can
still be false** (fake info).

**Step-by-Step Example**\

examine if the site itself looks legitimate.

**Common Mistakes & Tips**

-   ❌ "Padlock = always safe" → ✅ It only means encrypted; check
    source credibility too.

-   ❌ Entering private data on HTTP → ✅ Use **HTTPS** for
    forms/payments.

**Quick Practice (device)**\

form.\
**Low-Tech Option:** Sort example URLs into **encrypted** vs **not
encrypted**.

**Privacy & Safety Context**\

**Topic 10.2: Spotting Online Scams & Fake Pages**

RED FLAGS

**ATAL Level 1 -- Glossary (English Only)**

**A. General Computing**

-   **App / Application** --- A software program that does a task
    (calculator, browser, WhatsApp).

-   **Backup** --- A second copy of important files kept in another
    place (USB, cloud).

-   **Badge** --- A small award that shows progress or completion of a
    module or topic.

-   **Bandwidth** --- How much data can move through the internet
    connection in a second.

-   **Cloud** --- Online storage or services you reach through the
    internet.

-   **Compress (file/image)** --- Make a file smaller so it uses less
    storage and data.

-   **Consent** --- Permission given clearly before sharing photos,
    data, or recordings.

-   **Data (mobile data)** --- Internet usage measured in MB/GB.

-   **Device** --- A phone, tablet, or computer.

-   **Digital Footprint** --- What people can find about you online
    (posts, photos, comments).

-   **Download** --- Copy a file from the internet to your device.

-   **Folder** --- A container to organize files.

-   **Hotspot** --- Sharing one device's internet with another device.

-   **Incognito / Private Window** --- A browser mode that does not save
    history or cookies after you close it.

-   **KB / MB / GB** --- File sizes: 1,000 KB ≈ 1 MB; 1,000 MB ≈ 1 GB.

-   **Link (URL)** --- The web address you type or click to open a site.

-   **Local Copy** --- A file stored on your own device (not online).

-   **Log in / Log out** --- Enter/exit an account using a username and
    password.

-   **Low-Data Mode** --- Settings that reduce data use (lower video
    quality, fewer auto-downloads).

-   **Low-Tech Option** --- A paper or offline method to complete an
    activity without a device or internet.

-   **Offline-First** --- Designed to work without internet; internet is
    helpful but not required.

-   **OTP (One-Time Password)** --- A short code sent to your phone or
    email for extra security.

-   **Password** --- A secret string to secure an account.

-   **Permission (app)** --- Access an app requests (camera, mic, files,
    location).

-   **Pin / Shortcut** --- A quick way to open a file, folder, or app.

-   **Recycle Bin / Trash** --- A place where deleted files go before
    they are removed forever.

-   **Restart** --- Turn off and then turn on the device to refresh it.

-   **Save / Save As** --- Keep your work to storage / keep a copy with
    a new name or place.

-   **Screenshot** --- A picture of what is on your screen.

-   **Update** --- New fixes and features for apps or the operating
    system.

-   **Upload** --- Send a file from your device to a website or app.

-   **USB Drive** --- A small portable storage device you plug into a
    computer.

**B. Computer Parts & Performance (Module 1)**

-   **CPU (Central Processing Unit)** --- The "brain" that processes
    instructions.

-   **GPU** --- A graphics processor that helps with images and video
    (where applicable).

-   **HDD (Hard Disk Drive)** --- Larger, slower storage with moving
    parts.

-   **SSD (Solid State Drive)** --- Faster storage with no moving parts.

-   **Monitor / Screen** --- Shows text, images, and video (output).

-   **Keyboard / Mouse / Touch** --- Ways to give instructions (input).

-   **RAM (Random Access Memory)** --- Temporary work space for open
    apps; clears when power is off.

-   **Storage** --- Permanent memory that keeps files even when power is
    off.

**C. Operating System & Files (Module 2)**

-   **Archive (email/files)** --- Remove from the main list without
    deleting.

-   **Control Panel / Settings** --- Where you change system options.

-   **Desktop** --- The main screen where windows and icons appear.

**Troubleshooting & Guides**

**Read this first: 5-Step Quick Triage (2 minutes)**

1.  **Power & Cables** --- plugged in, switch ON, battery charge OK,
    router ON.

2.  **Restart** --- device and app (power off/on).

3.  **Storage** --- keep **≥15% free**; delete temp files/Downloads,
    empty Recycle Bin.

4.  **Network** --- check Wi-Fi/mobile data; test another site/app.

5.  **Update** --- OS/app updates; then retry.

**A. Common Issues (Standard Format)**

**How to read:** Each issue shows **Symptoms**, **Possible Causes**,
**Solutions**, and **When to seek help**. Follow steps **in order**; try
each step before moving on.

**Issue A1: Computer Won't Start**

**Symptoms:** No lights, no fan sound, black screen.\
**Possible Causes:** Power off, loose cable, drained battery, faulty
adapter.\
**Solutions:**

1.  Check wall switch/extension; test socket with another device.

2.  Reseat power cord/adapter; try a different socket.

3.  Laptop: charge 30--45 min, then hold **Power** for 10--15 sec.

4.  Remove USBs/SD/external displays; try again.\
    **When to seek help:** No signs of power after steps above or
    burning smell.

**Issue A2: Slow Device (PC or Phone)**

**Symptoms:** Lag, freezing, long load times.\
**Possible Causes:** Too many apps, low RAM/storage, background updates,
malware.\
**Solutions:**

1.  Close unused apps/tabs; restart.

2.  Free storage to **≥15%**; remove temp files/unused apps.

3.  Disable startup apps (PC: Task Manager → Startup).

4.  Run antivirus scan; install OS/app updates.\
    **When to seek help:** Still slow after cleanup and updates.

**Issue A3: No Internet / Slow Internet**

**Symptoms:** Pages don't load; videos buffer.\
**Possible Causes:** Router problem, weak signal, data used up, network
outage.\
**Solutions:**

1.  Test another site/app; try mobile data vs Wi-Fi.

2.  Move closer to router; reduce other downloads/streams.

3.  Reboot router (unplug 30 sec) and device.

4.  Check data balance/plan validity.\
    **When to seek help:** All devices affected for hours; contact ISP.

**Issue A4: Forgotten Password (Email/App)**

**Symptoms:** Can't log in.\
**Possible Causes:** Memory lapse, account compromise.\
**Solutions:**

1.  Use **Forgot Password**; choose SMS/alt-email recovery.

2.  Check if browser saved it (only if your **own device**).

3.  After recovery, turn on **2-step verification**.\
    **When to seek help:** Recovery not working or suspicious activity
    visible.

**Issue A5: Phone Storage Full**

**Symptoms:** "Storage full", can't update apps, camera stops.\
**Possible Causes:** Photos/videos, WhatsApp media, cache.\
**Solutions:**

1.  Delete large/duplicate videos; clear WhatsApp media from old chats.

2.  Uninstall unused apps; clear app cache (Settings).

3.  Move photos to **USB/computer**; keep one backup.\
    **When to seek help:** "Storage full" persists after cleanup.

**Issue A6: Email Not Sending**

**Symptoms:** Stuck in Outbox; error.\
**Possible Causes:** Offline, large attachments, server delay.\
**Solutions:**

1.  Check internet; send a **simple text** mail.

2.  Remove/resize attachments (keep under **25 MB** or share link).

3.  Wait 10--15 min; try again.\
    **When to seek help:** Text-only emails fail repeatedly.

**Issue A7: App Crashes or Won't Open**

**Symptoms:** App closes, freezes, won't launch.\
**Possible Causes:** Bug, outdated app, low RAM/storage, corrupted
data.\
**Solutions:**

1.  Close other apps; restart device.

2.  Update the app and OS.

3.  Clear app cache/data (note: data may reset).\
    **When to seek help:** Crashes continue after update/restart.

**Issue A8: WhatsApp Messages Not Delivered**

**Symptoms:** One tick, never delivered.\
**Possible Causes:** Poor internet, recipient offline, blocked, server
delay.\
**Solutions:**

1.  Check your internet; send to another contact to test.

2.  Ask recipient to confirm number/availability.

3.  Restart WhatsApp/device.\
    **When to seek help:** Fails to **many** contacts for hours.

**Issue A9: Computer Overheating**

**Symptoms:** Hot chassis, loud fan, sudden shutdowns.\
**Possible Causes:** Blocked vents, heavy apps, dust.\
**Solutions:**

1.  Use on hard, flat surface; keep vents clear.

2.  Close heavy apps; avoid direct sun.

3.  Clean vents with dry air (if safe) or get service cleaning.\
    **When to seek help:** Repeated thermal shutdowns or you're unsure
    about cleaning.

**Issue A10: Website Won't Load**

**Symptoms:** Only one site fails.\
**Possible Causes:** Site down, browser cache issue, DNS block.\
**Solutions:**

1.  Try another browser/device/network (mobile data).

2.  Clear cache/cookies; try again.

3.  Type address manually; avoid shortened links.\
    **When to seek help:** Many sites fail across devices/networks.

**Issue A11: Video Call --- Poor Quality**

**Symptoms:** Choppy video, audio delay.\
**Possible Causes:** Slow internet, too many running apps, Wi-Fi signal
weak.\
**Solutions:**

1.  Close other apps/tabs; pause large downloads.

2.  Move closer to router; switch to **audio-only** if needed.

3.  Ask others to pause heavy internet use.\
    **When to seek help:** Good internet but repeated call failures
    across platforms.

**Issue A12: Can't Download/Install Apps**

**Symptoms:** Store errors; download fails.\
**Possible Causes:** Low storage, weak internet, account issue.\
**Solutions:**

1.  Free storage; restart device.

2.  Connect to reliable Wi-Fi; retry.

3.  Sign out/in to the app store; update OS.\
    **When to seek help:** Fails on multiple apps with good
    storage/internet.

**Issue A13: PDF Won't Open**

**Symptoms:** Error on open.\
**Possible Causes:** No PDF reader, corrupted download.\
**Solutions:**

1.  Install/open with a **PDF reader** or browser.

2.  Re-download; compare file size.

3.  Try opening on another device.\
    **When to seek help:** Many PDFs from different sources all fail.

**Issue A14: Digital Payment Failed (UPI)**

**Symptoms:** Failed status; unsure about money.\
**Possible Causes:** Network/servers, low balance, wrong PIN.\
**Solutions:**

1.  Check balance; confirm recipient UPI ID/name.

2.  Wait 30--60 min; check app/SMS/passbook.

3.  Keep **screenshot** of transaction; DO NOT retry many times
    quickly.\
    **When to seek help:** Money debited but not received after 24
    hours---raise dispute in app/bank.

**Issue A15: Screen Too Dim/Bright**

**Symptoms:** Hard to read; eye strain.\
**Possible Causes:** Brightness/auto-brightness, battery saver.\
**Solutions:**

1.  Adjust brightness; disable battery saver.

2.  Turn off auto-brightness; clean screen.\
    **When to seek help:** Flicker or brightness controls don't respond.

**Issue A16: Keyboard/Typing Problems**

**Symptoms:** Keys not responding; wrong characters.\
**Possible Causes:** Wrong language/layout, stuck keys, USB/Bluetooth
issue.\
**Solutions:**

1.  Check **language/layout** in settings.

2.  Restart; try external keyboard (USB/Bluetooth).

3.  Clean gently around keys.\
    **When to seek help:** Physical damage or total failure on all apps.

**Issue A17: Microphone/Camera Not Working (Calls)**

**Symptoms:** Others can't hear/see you.\
**Possible Causes:** Muted mic, app permission off, device blocked.\
**Solutions:**

1.  Unmute in app and system; check input device.

2.  App permissions: allow **Microphone/Camera**.

3.  Close other apps using the camera/mic; restart.\
    **When to seek help:** Hardware fault suspected across multiple
    apps.

**Issue A18: Printer Not Working (if applicable)**

**Symptoms:** No print; stuck queue.\
**Possible Causes:** Cable/Wi-Fi issue, wrong printer, paused queue, no
paper/ink.\
**Solutions:**

1.  Check power/paper/ink; correct printer selected.

2.  Clear print queue; restart printer and PC.

3.  Reconnect USB/Wi-Fi; reinstall driver if needed.\
    **When to seek help:** Hardware errors or repeated jams.

**Issue A19: "File Won't Save" / Permission Denied**

**Symptoms:** Error when saving.\
**Possible Causes:** Saving to protected folder/USB locked, no space.\
**Solutions:**

1.  Save to **Documents** or Desktop first; then move.

2.  Check free space; rename with simple filename.

3.  Close from other apps; try **Save As** in a different folder.\
    **When to seek help:** Repeats across many folders and files.

**Issue A20: Browser Pop-Ups/Scam Warnings**

**Symptoms:** "Your PC is infected --- click to fix!"\
**Possible Causes:** Malicious site/ad; not real antivirus.\
**Solutions:**

1.  **Do not click**; close tab/browser.

2.  Run your **real antivirus** scan.

3.  Clear cache; avoid that site.\
    **When to seek help:** Pop-ups keep returning on many sites.

**C. When to Seek Professional Help (Immediately)**

-   **Liquid spills**, cracks, burning smell, repeated overheating
    shutdowns.

-   **Account security breach** (unknown logins, password reset emails).

-   **Financial disputes** (UPI debited/not received beyond 24h).

-   Persistent problems after you completed all steps above.
